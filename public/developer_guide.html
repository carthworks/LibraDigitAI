📦 Creating the Executable

Follow these steps to package the Electron application for distribution.

1. Prerequisites

  • Verify version is updated in package.json
  • Ensure backend environment is active
  • Check that no dev servers are running

2. Run Build Command

Open your terminal in the root directory and run:

npm run dist

This triggers electron-builder which packages the React frontend and bundles the Python backend.

3. Locate Output

The final installer will be generated in:

/dist/LibraDigit AI Setup 1.0.0.exe

🔑 Emergency Password Reset

WARNING: DATA LOSS RISK Resetting the password involves clearing the local database configuration. This should only be done if the user has absolutely lost access.

Since the app is offline-first, there is no "Forgot Password" email flow. To reset:

  1. Navigate to the user's AppData folder:
    %APPDATA%\LibraDigit AI\
  2. Locate the libradigit.db file. (Or checking inside the pyton backend older if running portable).
  3. Option A (Hard Reset): Delete libradigit.db.
    • Next launch acts as a fresh install.
    • User creates a new password.
    • Note: Previous project metadata history is lost, but original PDF files remain on disk.
  4. Option B (SQL Injection - Advanced):
    • Open DB with SQLite Browser.
    • Clear the auth_hash field in the config table.

🐛 Debugging & Uninstall

Uninstall Process

Standard Windows uninstall:

  1. Settings > Apps > Installed Apps
  2. Search "LibraDigit AI"
  3. Click "Uninstall"

Clean Uninstall: Manually delete %APPDATA%\LibraDigit AI to remove all local databases and logs.

Viewing Logs

Frontend Logs: Open app with Ctrl+Shift+I to view Console.

Backend Logs: Check the backend/logs/app.log file (if configured) or run the executable from CMD to see stdout.

⚡ Performance & Memory

Monitor and optimize the application's resource usage.

Process Management

  • Electron Main Process: Orchestrates the window. Low memory usage (~50MB).
  • Renderer Process: The React UI. Can grow with large lists. (<500MB is healthy).
  • Python Subprocess: The OCR engine.
    Warning: Loading Tesseract models can spike RAM usage.

Optimization Tip: If python.exe memory leaks, the app is designed to restart the subprocess on idle timeout.

🤝 User Support Scripts

Common responses for user inquiries.

User says: "The app is stuck on 'Initializing'..."

Response: "This usually means the background service is blocked. Please check if your Antivirus has quarantined server.exe or 'backend'. Try adding the Main Installation folder to your Antivirus Exclusions list."

User says: "OCR is gibberish..."

Response: "Check the resolution of your source PDF. Images below 300 DPI produce poor results. Also ensure the correct Language Pack (e.g., 'eng', 'fra') is selected in the dashboard before processing."
