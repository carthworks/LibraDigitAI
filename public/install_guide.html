LibraDigit AI

Electron Desktop App • Installation & Setup Guide

1

Pre-requisite: OCR Engine

LibraDigit AI requires Tesseract OCR to read documents.

Is it installed? Open Command Prompt and type tesseract --version.
If not found, download and install it from UB-Mannheim/tesseract.
2

Locate the Installer

Find the setup file (e.g., LibraDigitAI_Setup_1.0.0.exe) in your distribution folder.

3

Install & Security Check

Double-click the .exe file. As an internal secure tool, Windows SmartScreen may appear.

Click More Info > Run Anyway to proceed. This is normal for unsigned internal tools.

4

Launch & Login

Launch LibraDigit AI from your desktop. The app runs entirely offline for maximum security.

🔐 Setup Your Master Key:

On your first launch, you will be asked to create a new Master Password.

  • This password encrypts your local database.
  • It cannot be recovered if lost.
  • It ensures your archive remains private and offline.

🐛 Troubleshooting Guide

OCR Not Working?
Ensure Tesseract is in your system PATH environment variable. Restart the PC after installing Tesseract.


"Backend Connection Fail"?
This Electron app manages a local Python server. If it fails, check if an antivirus is blocking server.exe or port 5000.
