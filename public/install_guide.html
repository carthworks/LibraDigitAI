LibraDigit AI

Installation & Setup Guide for Librarians

1

Locate the Installer

Find the file named LibraDigitAI_Setup_1.0.0.exe in the folder provided to you. This is the complete application package.

2

Run Installation

Double-click the .exe file. Windows might ask for permission or show a "SmartScreen" warning since this is an internal tool. Click "Run Anyway" or "Yes" to proceed.

3

Launch Application

Once installed, you will find a LibraDigit AI icon on your desktop. Double-click to launch.

4

Login

The application is password protected to ensure secure access to the archive system.

🔐 Default Access Credentials:

Password: libradigit

🐛 Common Issues & Solutions

"Backend Not Connected" Error:
Close the application completely and restart it. The background scanning service needs a moment to initialize on the first run.


Files not saving:
Ensure you run the application with appropriate permissions if saving to a protected folder.

Need additional help? Contact your IT administrator.
