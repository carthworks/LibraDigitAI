## ✨ Feature 1: AI-Powered Metadata Extraction

### What is it?
AI automatically reads your document and suggests metadata (title, author, year, subject, keywords) - saving you 80% of manual entry time!

### How to use it:

1. **Upload and process your document** as usual
2. **Go to the Metadata page**
3. **Click the "Extract Metadata" button** (sparkle icon ✨)
4. **Review the AI suggestions** - each field shows a confidence score:
   - 🟢 **Green (70-100%)**: High confidence - usually accurate
   - 🟡 **Yellow (40-70%)**: Medium confidence - review carefully
   - 🔴 **Red (0-40%)**: Low confidence - likely needs editing

5. **Accept suggestions**:
   - Click ✓ **Accept** next to each field, OR
   - Click **Accept All** to fill all fields at once

6. **Edit if needed** - You can always manually edit any field
7. **Save** and continue!

### Tips:
- ✅ Works best with well-formatted documents
- ✅ Extracts from first page primarily
- ✅ Uses filename as fallback for title
- ✅ Supports 15 subject categories
- ✅ Completely offline - no data sent to cloud

## 📦 Feature 2: Batch Processing

### What is it?
Upload and process **multiple documents at once** instead of one-by-one. Process 50 documents in the time it used to take for 10!

### How to use it:

1. **Click "Batch Processing"** in the sidebar menu
2. **Drag & drop multiple files** into the upload zone
   - Or click to browse and select multiple files
   - Supports: PDF, PNG, JPG, TIFF, BMP

3. **Optional**: Give your batch a name (e.g., "History Collection 2025")
4. **Click "Upload & Process All"**
5. **Watch the progress**:
   - Overall progress bar shows completion %
   - Individual file status (✓ completed, ✗ failed, ⏳ pending)
   - Estimated time remaining

6. **When complete**:
   - All files are OCR'd and ready
   - Go to each document for cleanup and metadata
   - Use AI metadata extraction to speed up the process!

### Tips:
- ✅ Recommended: 10-50 files per batch
- ✅ Files process in the background
- ✅ You can cancel anytime
- ✅ Failed files don't stop the batch
- ✅ View batch history to track past uploads

## 🎯 Recommended Workflow

### For Single Documents:
```
Upload → OCR → Cleanup → AI Metadata → Save → Archive
         (automatic)      (click ✨)
```

### For Batch of Documents:
```
Batch Upload → Wait for OCR → For each document:
                                - Cleanup
                                - AI Metadata (click ✨)
                                - Accept All
                                - Save
```

## 🆘 Troubleshooting

### AI Metadata Not Extracting?
- ✅ Make sure OCR is completed first
- ✅ Check that document has text (not blank pages)
- ✅ Try re-running OCR if text is missing

### Batch Upload Not Working?
- ✅ Check file types (PDF, PNG, JPG, TIFF, BMP only)
- ✅ Try smaller batches (10-20 files)
- ✅ Check disk space
- ✅ Restart backend server if needed

### Low Confidence Scores?
- ✅ Normal for poorly formatted documents
- ✅ Always review low-confidence suggestions
- ✅ Manually edit as needed
- ✅ Use filename as title fallback
