# Handwritten Text to PDF Conversion - Feature Documentation

## Overview

LibraDigit AI now includes a powerful **Handwritten Text to PDF Converter** that transforms handwritten notes images into clean, professionally formatted PDF documents with extracted text.

## Features

### 🎯 Core Capabilities

1. **Specialized Handwriting Recognition**
   - Uses LSTM neural network (OEM 1) for better handwriting accuracy
   - Enhanced preprocessing specifically tuned for handwritten text
   - CLAHE (Contrast Limited Adaptive Histogram Equalization) for better contrast
   - Advanced denoising and sharpening

2. **Intelligent Structure Detection**
   - Automatic title detection
   - Heading identification
   - Bullet point and list recognition
   - Diagram and technical content detection
   - Paragraph segmentation

3. **Professional PDF Formatting**
   - Clean, readable layout
   - Custom typography and styling
   - Structured sections (title, headings, paragraphs, lists, diagrams)
   - Complete extracted text section
   - Metadata footer with word/line counts

4. **Image Preprocessing Pipeline**
   - Grayscale conversion
   - Advanced denoising (Non-Local Means)
   - CLAHE contrast enhancement
   - Adaptive thresholding
   - Morphological operations
   - Sharpening filters

## How It Works

### Processing Pipeline

```
1. Image Upload
   ↓
2. Specialized Preprocessing
   - Denoise (h=15)
   - CLAHE enhancement
   - Adaptive thresholding
   - Morphological cleanup
   ↓
3. Handwriting OCR
   - LSTM neural network
   - PSM 4 (single column)
   - Language-specific recognition
   ↓
4. Structure Analysis
   - Title detection
   - Heading identification
   - List extraction
   - Diagram detection
   ↓
5. PDF Generation
   - Professional formatting
   - Multi-section layout
   - Typography styling
   ↓
6. Output
   - Formatted PDF file
   - Extracted text in database
```

## Image Preprocessing Details

### 1. Denoising
```python
cv2.fastNlMeansDenoising(gray, None, h=15, templateWindowSize=7, searchWindowSize=21)
```
- Removes noise while preserving edges
- h=15 for stronger denoising (handwriting can be noisy)

### 2. CLAHE Enhancement
```python
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
enhanced = clahe.apply(denoised)
```
- Improves local contrast
- Better for varying lighting conditions
- Enhances faded handwriting

### 3. Adaptive Thresholding
```python
cv2.adaptiveThreshold(
    enhanced, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    blockSize=15,
    C=10
)
```
- Local thresholding for better results
- Handles uneven lighting
- Preserves handwriting details

### 4. Morphological Operations
```python
kernel = np.ones((2,2), np.uint8)
cleaned = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
```
- Connects broken strokes
- Fills small gaps
- Improves character recognition

## Structure Detection Heuristics

### Title Detection
- First significant line (> 3 characters)
- Usually at the top of the page
- Formatted prominently in PDF

### Heading Detection
- Short lines (< 50 characters)
- Contains uppercase letters
- Not part of continuous paragraph

### List Detection
- Lines starting with: -, *, •, numbers
- Followed by period, parenthesis, or colon
- Grouped as bullet points

### Diagram Detection
- Lines containing special characters:
  - Arrows: →, ←, ↑, ↓
  - Boxes: ─, │, ┌, ┐, └, ┘
  - Connectors: |, -, ~
- Formatted with monospace font

## Best Practices

### For Best Results

1. **Image Quality**
   - Use 300 DPI or higher
   - Ensure good lighting (no shadows)
   - Avoid glare and reflections
   - Keep camera/scanner steady

2. **Handwriting**
   - Write clearly and legibly
   - Use dark ink (black or blue)
   - Avoid very light or faded writing
   - Maintain consistent size

3. **Page Setup**
   - Use lined or grid paper for structure
   - Avoid wrinkled or folded pages
   - Ensure full page is visible
   - Remove any background objects

4. **Content Organization**
   - Use clear headings
   - Separate paragraphs with space
   - Use bullet points for lists
   - Label diagrams clearly

## Troubleshooting

### Common Issues

**Problem:** Low accuracy on handwritten text
**Solution:**
- Ensure handwriting is clear and legible
- Use higher resolution images (300+ DPI)
- Improve lighting conditions
- Try different Tesseract language packs

**Problem:** PDF formatting looks wrong
**Solution:**
- Check if structure detection is working
- Verify text is being extracted correctly
- Try with clearer handwriting
- Adjust image preprocessing if needed

**Problem:** Diagrams not detected
**Solution:**
- Ensure diagrams use standard characters (arrows, lines)
- Draw diagrams clearly with good contrast
- Separate diagrams from regular text

**Problem:** Processing is slow
**Solution:**
- Reduce image size before upload
- Use JPEG instead of PNG for smaller file size
- Ensure system has sufficient RAM
- Close other applications

## API Reference

### HandwrittenToPDFConverter Class

#### Methods

**`__init__()`**
- Initializes the converter
- Sets up PDF styles

**`preprocess_handwritten_image(image_path: str) -> Image`**
- Preprocesses image for handwriting OCR
- Returns enhanced PIL Image

**`extract_handwritten_text(image_path: str, language: str) -> Dict`**
- Extracts text from handwritten image
- Returns dict with text and statistics

**`generate_formatted_pdf(extracted_data: Dict, output_path: str, title: str) -> bool`**
- Generates formatted PDF from extracted data
- Returns success status

**`convert_handwritten_to_pdf(image_path: str, output_path: str, title: str, language: str) -> Dict`**
- Complete conversion workflow
- Returns result with success status and metadata
