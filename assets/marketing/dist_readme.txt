QUICK START INSTRUCTIONS
------------------------------------------------------------------------

STEP 1: INSTALL OCR ENGINE (REQUIRED)
   This application requires "Tesseract OCR" to read text from images.
   - If not installed, download it here: 
     https://github.com/UB-Mannheim/tesseract/wiki
   - IMPORTANT: During installation, check "Additional Script Data" 
     if you need languages other than English.

STEP 2: INSTALL LIBRADIGIT AI
   - Double-click "LibraDigitAI_Setup_1.0.0.exe".
   - If Windows SmartScreen appears (Blue window), click:
     "More Info" -> "Run Anyway"
   - Follow the on-screen prompts.

STEP 3: LAUNCH & SETUP
   - Launch the app from your Desktop.
   - Create your master password on the first screen.
   - Drag and drop a PDF to start archiving!
